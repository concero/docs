# Enabling a New Class of Applications

Concero is messaging infrastructure for apps that need reliable, configurable cross-chain execution.

![Concero's Applications Possibilities](/images/concero-v2-use-cases.png)

## Common use cases

- **DeFi coordination**
Cross-chain actions such as risk updates, strategy execution, or settlement triggers.

- **Cross-chain governance**
Send proposal decisions and execute governance actions across networks.

- **Interoperable game and identity systems**
Synchronize state and ownership logic between chains.

- **Enterprise and operational workflows**
Coordinate state changes across private/public environments with explicit verifier policy.

## What makes these possible

- Per-message relayer and verifier selection.
- Destination-side verification in app contracts.
- Deterministic message receipts for indexing and replay-safe handling.

## Builder guidance

Start with strict defaults (`ConceroClient`, allowlisted modules, clear verification count), then loosen policy only where needed.
