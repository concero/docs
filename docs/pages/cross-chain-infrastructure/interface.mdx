# Interface

## Concero router
### Send message

```solidity
function sendMessage(MessageRequest calldata messageReq) external returns (bytes32)
```

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| messageReq | struct MessageRequest | struct containing the message request data |


### Get fee

```solidity
function getFee(uint64 dstChainSelector, feeToken address, dstChainGasLimit uint32) external view returns (uint256)
```

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| dstChainSelector | uint64 | destination chain selector |
| feeToken | address | token address to pay the fee |
| dstChainGasLimit | uint32 | gas limit on destination chain to process the message |

## Concero client 
### Receive message

```solidity
function conceroReceive(Message calldata message) external
```

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| message | struct Message | struct containing the message data |

## Types

### MessageRequest
```solidity
    struct MessageRequest {
        address feeToken;
        address receiver;
        uint64 dstChainSelector;
        uint32 dstChainGasLimit;
        bytes data;
    }
```

### Message
```solidity
    struct Message {
        bytes32 id;
        uint64 srcChainSelector;
        address sender;
        bytes data;
    }
```
