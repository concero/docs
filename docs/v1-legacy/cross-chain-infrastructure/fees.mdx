# Fees

## Overview
Concero cross-chain infrastructure is designed to be as cost-effective as possible. The fees are split into three categories:

## Fees Breakdown

| Fee Type                        | Description                                                                 |
|---------------------------------|-----------------------------------------------------------------------------|
| Chainlink Function Fees         | Covers the cost of two Chainlink Function executions                        |
| Concero Fee                     | A fixed fee of 1 cent charged by Concero                                    |
| Messenger Gas Fee               | Covers the gas costs for message delivery on the destination chain, which vary based on the gas prices on the destination chain |
